# Privacy by Design

- **Data Minimization:** collect answers about exposure, not the sensitive values themselves.
- **Purpose Limitation:** assessment data is used only to calculate privacy-risk categories.
- **Least Privilege:** the application has no social-media scraping or account-access capability.
- **Privacy by Default:** the demo never asks for passwords, phone numbers, addresses, private messages, or exact locations.
- **Transparency:** the score is labeled as an educational framework and its assumptions are documented.
- **User Control:** users voluntarily submit questionnaire responses and can use the simulator without changing real accounts.
- **Retention Limitation:** the database stores assessment results, not the questionnaire's sensitive personal values.
- **Secure Processing:** validation is performed server-side and the project is designed for local execution.
