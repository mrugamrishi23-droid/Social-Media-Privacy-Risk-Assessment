# Photo and Metadata Awareness

Photos can reveal location context, workplace/school details, vehicle information, badges, documents, computer screens, family information, or travel context.

EXIF metadata can sometimes contain fields such as capture time, camera information, or GPS coordinates. This project does not infer hidden location beyond metadata explicitly present. A future safe local-only viewer could read metadata from a voluntarily uploaded image, display available fields, and remove metadata from a copy without uploading the original externally.
