# System Architecture

Input Validation

Profile / Personal Info / Location / Content / Connections / Tagging /
Account Security / Third-Party Apps / Social Engineering / Digital Footprint Analyzers

Category Scores
↓
Configurable Risk Scoring Engine
↓
Overall Risk + Risk Level
↓
Findings Engine
↓
Recommendation Engine
↓
Privacy Dashboard
↓
Privacy Report

Optional anonymized aggregates are stored as assessment scores, categories and risk levels.
No phone numbers, email addresses, passwords, exact locations, private messages, or birth dates are stored.
