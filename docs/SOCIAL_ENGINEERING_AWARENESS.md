# How Oversharing Can Increase Social-Engineering Risk

Public context such as employer, college, travel plans, family references, interests, and public events can sometimes make unwanted messages more believable. The framework therefore measures behaviors such as accepting unknown connections, clicking unexpected links, sharing verification codes, and trusting impersonated accounts.

This project intentionally does **not** generate personalized attack messages, identify real people, enumerate accounts, or scrape profiles. The purpose is defensive awareness.
